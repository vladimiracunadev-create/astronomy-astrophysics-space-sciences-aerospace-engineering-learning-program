# Soporte

## Antes de solicitar ayuda

1. revisa el [README](README.md), la [documentación](documentacion/README.md) y el [estado](STATUS.md);
2. ejecuta `python herramientas/validar_catalogo.py` si el problema es estructural;
3. busca una incidencia existente;
4. confirma que no estás interpretando los 5.120 registros E0 como clases terminadas.

## Qué incluir

Indica objetivo, archivo o ID exacto, revisión, sistema, comando, salida observada, resultado esperado y evidencia mínima reproducible. Para dudas de licencia, identifica el componente y su procedencia; para fuentes, añade organismo, título, edición, fecha y localizador.

## Límites

El proyecto no ofrece soporte de misión, certificación, asesoría legal ni garantía de respuesta. Las preguntas de seguridad sensibles deben seguir [SECURITY.md](SECURITY.md), no una incidencia pública.
