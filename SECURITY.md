# Seguridad

## Alcance

Este repositorio publica documentación, catálogos, scripts locales y un visor estático. No opera naves, instrumentos, lanzamientos ni infraestructura crítica. Los ejemplos futuros serán educativos y no sustituirán análisis, certificación ni supervisión profesional.

## Reportar una vulnerabilidad

No publiques credenciales, datos personales, procedimientos de explotación ni detalles que faciliten daño en una incidencia pública. Utiliza la opción privada **Report a vulnerability** de GitHub cuando esté disponible. Incluye componente, revisión, impacto, pasos mínimos de reproducción y mitigación propuesta.

## Qué se considera relevante

- ejecución inesperada o inyección en herramientas o visor;
- publicación de secretos o información personal;
- dependencia o Action comprometida;
- contenido que permita confundir una simulación con una capacidad operacional;
- instrucciones peligrosas sin contexto, límites, ética o controles.

La recepción se acusará cuando exista un canal habilitado. La prioridad dependerá de impacto y reproducibilidad; no se prometen plazos de servicio. Los hallazgos de contenido se tratan además bajo el estándar pedagógico y científico.
