# Índice de archivos

| Necesidad | Punto de entrada |
|---|---|
| entender propósito y estado | `README.md`, `STATUS.md` |
| recorrer las 2.077 clases del programa | `PROGRAMA_ACADEMICO_COMPLETO.md`, `catalogo/estructura/` |
| consultar la línea base inicial (5.120 registros) | `catalogo/clases.jsonl` |
| comprender estructura y carga futura | `SYLLABUS.md`, `documentacion/SYLLABUS_Y_CARGA.md` |
| redactar o evaluar una clase futura | `documentacion/ESTANDAR_PEDAGOGICO_Y_DE_EVALUACION.md` |
| planificar implementación | `ROADMAP.md`, `documentacion/PLAN_DE_IMPLEMENTACION_Y_ESTADOS.md` |
| elegir una ruta profesional | `documentacion/MAPA_DE_RUTAS_PROFESIONALES.md` |
| gestionar fuentes y evidencia | `documentacion/ESTANDAR_DE_FUENTES.md`, `documentacion/FUENTES_Y_EVIDENCIA.md` |
| interpretar licencias | `documentacion/LICENCIAS_Y_PROCEDENCIA.md`, `documentacion/LICENSING_MATRIX.md` |
| contribuir | `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` |
| reportar seguridad o pedir ayuda | `SECURITY.md`, `SUPPORT.md` |
| validar o generar huellas | `herramientas/validar_catalogo.py`, `herramientas/generar_manifiesto.py` |

Los inventarios canónicos están en `catalogo/` y `metadatos/`. La carpeta `programa/` ofrece vistas editoriales derivadas; `visor/` es la interfaz estática publicada.
