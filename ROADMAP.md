# Roadmap del programa

Este roadmap resume la resolución del repositorio y de sus contenidos. El detalle operativo, los artefactos y las condiciones de cierre están en el [plan de implementación](documentacion/PLAN_DE_IMPLEMENTACION_Y_ESTADOS.md).

## Línea base `0.1.0` · publicada como catálogo

- [x] 5.120 IDs estables con título y descripción preliminar.
- [x] 64 bloques transversales y 24 rutas con 192 módulos.
- [x] Catálogo equivalente en JSONL, JSON y CSV.
- [x] Visor estático con búsqueda y filtros.
- [x] Validador reproducible de estructura y estado preliminar.
- [x] Estándar `clase-profunda-cientifica` y estados E0–E6 documentados.
- [ ] Clases completamente redactadas y verificadas: **0/5.120**.

## Horizonte A · integridad y publicación

- [x] Documentar alcance, estado, estándar y puertas de calidad.
- [x] Añadir validación continua del catálogo.
- [x] Preparar publicación del visor con GitHub Pages.
- [ ] Confirmar ejecución verde en el repositorio público.

**Cierre:** catálogo sincronizado, CI verde, visor publicado y metadatos públicos coherentes.

## Horizonte B · piloto B01

- [ ] Llevar B01-C01–B01-C20 de E0 a E5.
- [ ] Auditar dependencias, fuentes, ejercicios, soluciones y accesibilidad.
- [ ] Documentar carga, repetición, errores y decisiones editoriales.

**Cierre:** 20 clases E5 y un informe que autorice o corrija el método antes de escalar.

## Horizontes C–F · tronco transversal

- [ ] B02–B08: observación, historia, fundamentos e informática inicial.
- [ ] B09–B16: matemática, datos, computación y control.
- [ ] B17–B40: astrofísica, observación y ciencias planetarias.
- [ ] B41–B64: astrodinámica, ingeniería, operaciones y sociedad.

**Cierre por bloque:** todas las clases en E5, dependencias auditadas, proyecto integrador y revisión disciplinar registrada.

## Horizonte G · rutas R01–R24

- [ ] Resolver módulos por ruta reutilizando el tronco común.
- [ ] Añadir diagnóstico, checkpoints, proyecto final y criterio de salida.
- [ ] Probar que no hay duplicación mecánica con bloques ya desarrollados.

**Cierre por ruta:** ocho módulos E5, evidencia acumulativa y límites profesionales explícitos. La ruta no se presenta como titulación independiente.

## Horizonte H · pilotaje y mantenimiento

- [ ] Elevar clases seleccionadas de E5 a E6 mediante pilotos éticos.
- [ ] Medir accesibilidad, tiempo, errores y transferencia.
- [ ] Mantener fuentes, normas, software y datos por versión y fecha.

**Cierre:** informes públicos de pilotaje y cambios trazables; la mejora continúa y no se declara «terminada» de forma permanente.

## Regla de avance

Una casilla sólo se marca al existir evidencia en el repositorio. La redacción automatizada, el conteo de palabras o la presencia de una plantilla no bastan para avanzar una clase. Ningún horizonte autoriza renumerar IDs ni modificar otros programas de aprendizaje.
