# Cómo usar el programa

## Para aprender

1. define una meta y una ruta profesional;
2. realiza un diagnóstico de capacidades, no sólo de temas conocidos;
3. selecciona prerrequisitos transversales y módulos pertinentes;
4. avanza cuando puedas presentar la evidencia indicada;
5. conserva resultados, retroalimentación y revisiones en un portafolio.

Mientras las unidades permanezcan en E0, el catálogo sirve para planificar y auditar cobertura, no para estudiar una clase terminada.

## Para diseñar contenidos

Empieza con un piloto pequeño. Resuelve E1 y E2 antes de redactar; después completa las 22 funciones, revisa precisión y accesibilidad, y sólo cuenta la unidad como desarrollada cuando alcance E5. No generes contenido masivo para simular progreso.

## Para integrar otros programas

Intercambia IDs, prerrequisitos, resultados y manifiestos mediante metadatos. No copies ni edites repositorios ajenos y no conviertas rutas compartidas en programas duplicados.
