# Estándar de fuentes

Toda afirmación relevante deberá vincularse con una fuente que realmente permita sostenerla.

## Registro mínimo

- autor u organismo y título;
- edición, versión, revisión o fecha de publicación;
- URL, DOI, ISBN u otro localizador persistente;
- sección, tabla, figura, ecuación o páginas consultadas;
- fecha de consulta cuando el recurso sea mutable;
- afirmación respaldada y función pedagógica;
- licencia, permiso y límite de reutilización;
- jurisdicción y vigencia cuando corresponda.

## Jerarquía práctica

Se prefieren datos de misión con procedencia, artículos primarios, documentación técnica oficial, normas vigentes y revisiones académicas reconocidas. Una fuente secundaria puede explicar o localizar, pero no reemplaza evidencia primaria en decisiones críticas.

## Prohibiciones

No se inventan citas ni se usa una página de resultados como fuente final. No se reproduce una obra completa por estar accesible. No se interpreta una referencia preliminar como lectura verificada, conformidad normativa o autorización de uso.
