# Fuentes y evidencia

## Estados de una fuente

| Estado | Significado |
|---|---|
| localizada | se conoce un identificador o URL plausible |
| registrada | tiene metadatos mínimos y procedencia |
| consultada | se revisaron partes identificadas |
| evaluada | se documentaron autoridad, actualidad, alcance y límites |
| aplicada | respalda una afirmación concreta con localizador |
| revisada | otra persona comprobó la relación entre afirmación y fuente |

Las 25 referencias actuales y sus 832 relaciones son preliminares: no superan automáticamente estos estados.

## Evidencia reproducible

Una afirmación científica debe permitir recuperar datos, transformación, método, unidades, sistema de referencia, versión, tolerancia e incertidumbre. Una afirmación pedagógica debe enlazar resultado, actividad, evidencia y criterio. Una afirmación de estado debe derivarse del catálogo o de artefactos verificables.

Cuando fuentes autorizadas discrepen, la clase futura presentará el desacuerdo, el contexto y la decisión adoptada; no ocultará la incertidumbre con una cifra única.
