# Mapa de dependencias

Las dependencias curriculares se expresan como capacidades observables, no sólo como IDs o temas.

```text
diagnóstico → fundamentos transversales → métodos y herramientas
→ especialización por ruta → integración → proyecto o investigación
```

Toda relación futura indicará tipo —prerrequisito, correquisito, recomendación o reutilización—, capacidad requerida, evidencia aceptable y consecuencia de omitirla. Las ampliaciones serán aditivas; no se borran ni renumeran IDs existentes.

Los controles deberán detectar ciclos, prerrequisitos ausentes, saltos de nivel, unidades sin continuidad y dependencias que sólo repiten un título. La integración con otros programas se documentará por manifiesto y metadatos, sin modificar el proyecto externo.
