# Portafolio y evidencias

El portafolio futuro demostrará capacidades mediante artefactos revisables, no asistencia ni volumen de texto.

Cada evidencia conservará ID de clase, resultado evaluado, versión, fecha, datos y herramientas, licencia, criterios, primera entrega, retroalimentación, revisión, comprobaciones y asuntos abiertos. Código, cálculos, simulaciones y visualizaciones deben ser reproducibles dentro de tolerancias declaradas.

Los productos pueden incluir bitácoras de observación, análisis de datos, modelos, diseños, informes técnicos, revisiones, presentaciones o protocolos. Se evitará publicar datos personales, credenciales, material restringido o información operacional sensible.

Una muestra de portafolio no equivale por sí sola a certificación profesional; describe evidencia obtenida bajo condiciones documentadas.
