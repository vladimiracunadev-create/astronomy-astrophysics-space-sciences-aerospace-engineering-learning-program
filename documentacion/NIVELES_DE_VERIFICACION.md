# Niveles de verificación

Los niveles siguientes describen confianza en una afirmación o artefacto; no sustituyen N0–N5 ni E0–E6.

| Nivel | Condición mínima |
|---|---|
| V0 · declarado | existe una afirmación sin comprobación independiente |
| V1 · estructural | formato, campos, conteos y relaciones son válidos |
| V2 · reproducido | otra ejecución obtiene el mismo resultado dentro de tolerancia |
| V3 · contrastado | se compara con caso analítico, fuente o implementación independiente |
| V4 · revisado | una persona competente examina método, datos, límites y evidencia |
| V5 · validado en contexto | el artefacto se prueba con usuarios o entorno pertinente y registra resultados |

Siempre se declara qué se verificó, quién o qué lo comprobó, revisión, datos, tolerancia y limitaciones. La validación del catálogo actual es V1 documental y no demuestra que las clases estén redactadas.
