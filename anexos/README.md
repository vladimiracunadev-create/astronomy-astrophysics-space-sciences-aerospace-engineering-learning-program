# Anexos históricos y pedagógicos

[🏠 Volver al programa](../README.md) · [🔤 Glosario](../glosario/README.md) · [📚 Programa completo](../PROGRAMA_ACADEMICO_COMPLETO.md)

Los anexos son lecturas de contexto para el programa: cuentan **quién hizo qué, cuándo y por qué importa**, y llevan a los bloques donde cada tema se estudia con método. No reemplazan a las clases: las acompañan con historia, personas e instituciones.

> **Estado.** Textos de síntesis propia, pendientes de revisión disciplinar y de contraste con fuentes primarias (nivel E0, como todo el programa). Las fechas son las del hecho principal; las cifras están redondeadas. Antes de citar un dato en un trabajo, contrástalo con la fuente oficial indicada en la ficha.

## Cómo usarlos

1. **Antes de una clase:** lee la ficha relacionada para ubicar el tema en la historia.
2. **Después de una clase:** usa las preguntas de estudio para conectar con instituciones, personas y decisiones.
3. **En un proyecto:** elige una misión o persona y reconstruye problema, método, resultado y legado.
4. **Para buscar un término:** el [glosario](../glosario/README.md) define las palabras técnicas que aparecen aquí.

## Criterios editoriales

- Cada ficha dice **qué fue**, **qué aportó** y **qué enseña**.
- Se evitan los mitos: cuando una anécdota es dudosa o simplificada, se nombra el matiz.
- Se incluye la dimensión humana y ética: crédito, exclusión, riesgo, contexto político.
- No se reproducen textos protegidos; las descripciones son redacción propia.
