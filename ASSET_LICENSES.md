# Licencias y procedencia de activos

**Inventario revisado:** 5 de noviembre de 2026.

## Estado actual

El repositorio no incorpora fotografías, audio, video, modelos 3D, logotipos institucionales, tipografías redistribuidas ni ilustraciones externas. El visor utiliza HTML, CSS y JavaScript propios sin dependencias de recursos remotos.

| Ruta o familia | Procedencia | Régimen |
|---|---|---|
| `visor/index.html` | interfaz y estilos funcionales propios; catálogo embebido generado | código separable Apache-2.0; texto y catálogo originales `CC BY-NC-SA 4.0` |
| futuros diagramas originales | creados para el programa | `CC BY-NC-SA 4.0`, salvo aviso específico |
| futuras salidas PDF o HTML | generadas desde fuentes del repositorio | cada componente conserva la licencia de su fuente |

## Regla de incorporación

Todo activo futuro debe registrar ruta, autor, fuente, licencia, cambios, atribución exigida y permiso de redistribución. Si el régimen no está claro, se enlaza el recurso en vez de copiarlo.

Logotipos, emblemas, imágenes astronómicas, mapas, fotografías de observatorios, diagramas institucionales y capturas de software continúan bajo los derechos de sus titulares. Su mención no implica patrocinio ni autorización.
