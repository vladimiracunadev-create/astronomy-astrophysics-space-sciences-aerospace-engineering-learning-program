# Código de conducta

Este proyecto espera colaboración respetuosa, verificable e inclusiva.

## Conductas esperadas

- cuestionar ideas con evidencia sin atacar personas;
- reconocer incertidumbre, autoría, licencias y límites profesionales;
- usar lenguaje accesible y respetar diferencias culturales, territoriales y de experiencia;
- corregir errores de forma trazable;
- proteger privacidad y seguridad, especialmente ante participantes menores o comunidades vulnerables.

No se aceptan acoso, discriminación, amenazas, divulgación de datos privados, atribución falsa, plagio, manipulación de evidencia ni promoción irresponsable de riesgos. Las contribuciones pueden moderarse o rechazarse para proteger a la comunidad y la integridad académica.

Reporta incidentes por un canal privado del mantenedor cuando exista. Incluye sólo la información necesaria y no expongas a terceros. Esta política se aplica a repositorio, revisiones, discusiones y espacios oficiales asociados.
