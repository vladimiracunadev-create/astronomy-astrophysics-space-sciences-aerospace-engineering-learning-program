# Estudio relámpago

1. Pregunte meta, tiempo, nivel y tema fuerte/débil.
2. Con `python herramientas/consulta_programa.py tema "<t>" --texto -n 10` (y `bloque Bxx`) elija un máximo de 6–8 clases núcleo; añada 2–3 simuladores del sitio (trayectorias, misiones, asistencias, calendario) y 1 taller `talleres/T0x` afín.
3. Distribuya en bloques de 50 min (leer → simular → ejercicio con `calculadora_cientifica.py` → autoevaluación de 3 preguntas) con pausas y 20 % de margen.
4. Termine con un repaso de errores y una hoja de 1 página con fórmulas, órdenes de magnitud y datos clave (con fuente).
5. Recuerde que las clases están pendientes de revisión: contraste los datos críticos con fuentes oficiales.
