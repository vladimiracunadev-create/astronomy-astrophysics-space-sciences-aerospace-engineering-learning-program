# Revisar rigor y fuentes

1. Liste cada afirmación cuantitativa y cada afirmación sobre una misión real.
2. Compruebe: unidades y conversión (`calculadora_cientifica.py convert/calc`), órdenes de magnitud, coherencia interna y sistema de referencia.
3. Contraste con los datos del repositorio (simuladores, `simuladores/datos`, talleres `talleres/`) y con la fuente pública citada. Si no hay fuente pública verificable: ⚠.
4. Revise que no se presenten como hechos los repartos ilustrativos ni se use «verificado/revisado» para las clases del programa (están pendientes de revisión).
5. Devuelva una tabla: afirmación | verificación | resultado (correcto / corregir / ⚠ sin fuente) | corrección propuesta.
